Question-1: What are the different ways to select an element in the DOM?

There are five main methods used to grab elements from a webpage:
document.getElementById('id'): Selects a single element by its unique id.
document.getElementsByClassName('class'): Selects all elements with a specific class name (returns a live collection).
document.getElementsByTagName('tag'): Selects all elements of a specific HTML tag type (like p, div, li).
document.querySelector('selector'): Modern and flexible. Uses CSS selectors (like #id, .class, or div > p) to find the first matching element.
document.querySelectorAll('selector'): Uses CSS selectors to find all matching elements (returns a static NodeList).

Question-2: What is the difference between innerHTML, innerText, and textContent ?

While they all deal with what's inside an element, they see things differently:
innerHTML: Returns or sets the actual HTML markup inside an element. If you type Hi, it renders bold text.
innerText: Returns or sets the visible text as it appears on the screen. It respects CSS styling (e.g., it won't show text hidden with display: none).
textContent: Returns or sets the raw text exactly as it is written in the code. It includes spacing and hidden text, but completely ignores HTML tags.

Question-3: What is event delegation in the DOM?

Event delegation is a technique where you attach a single event listener to a parent element instead of adding separate listeners to multiple child elements. Because of how events move up the DOM tree, the parent can catch the event, check which specific child (event.target) was clicked, and handle it accordingly. This is highly efficient and works even for new child elements added to the page later.

Question-4: What is event bubbling in the DOM?

Event bubbling is the default way events travel in the DOM. When an event (like a click) happens on an element, it doesn't just stop there. The event "bubbles" straight up like an air bubble in water—triggering the same event on its parent, then its grandparent, all the way up to the document and window. Note: You can stop this upward chain reaction anywhere you want by calling event.stopPropagation() inside your event function.

Question-5: How do you create, add, and remove elements using JavaScript?

1. Create an element Use document.createElement() and pass it the HTML tag you want.
2. Add an element Target an existing parent element and use appendChild() or append() to put your new element inside it.
3. Remove an element Target the element you want to get rid of and call .remove().
